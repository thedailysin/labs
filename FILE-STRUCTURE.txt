THE DAILY SIN PORTFOLIO — PLAIN HTML STRUCTURE

index.html
  Homepage. The rotating project title opens its project page.
  Selecting either filter opens the matching category page.

category-template.html
  Reusable category page.
  Example: category-template.html?type=industry&value=Education
  Every project card opens project-template.html with its project information.

project-template.html
  Reusable project page.
  Reads project information from its URL for now.
  The Next Project block links to the next project.
  Header links return home or open About me.

about.html
  About page. Biography, email and contact links live here.

assets/studio-seal.png
  Shared Studio by The Daily Sin seal used in every page header.

assets/logo-motion.js
  Shared spring rotation used by the seal on mouse-wheel movement.

START HERE
  Open index.html. All active pages link to one another using relative links,
  so the folder can be uploaded to GitHub or previewed locally as-is.

LATER MEDIA ORGANISATION
  assets/images/[project-slug]/
  assets/videos/[project-slug]/
  Keep large videos outside GitHub if storage becomes a problem.
